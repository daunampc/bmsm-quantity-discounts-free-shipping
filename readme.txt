Dynamic WooCommerce quantity discount tiers with a custom Free Shipping method.

== Features ==
- Admin menu under WooCommerce > Buy More Save More.
- Add or remove unlimited discount tiers.
- Applies the highest matching enabled tier.
- Adds a clean custom Free Shipping method when cart quantity reaches the configured threshold.
- Can keep other shipping methods visible while adding Free Shipping.
- Can hide existing WooCommerce Free Shipping until eligible.
- Optional Free Shipping Only Mode: do not apply percentage discounts once free shipping is unlocked.

== Default Rules ==
- Buy 2 Save 5%
- Buy 3 Save 7%
- Free Shipping from 4 items
- Keep other shipping methods visible
- Hide WooCommerce Free Shipping until eligible
- Free Shipping Only Mode enabled
