# BMSM Quantity Discounts + Free Shipping

Version: **1.0.0**  
Author: **toshstack**

WooCommerce plugin for quantity-based cart discounts, free shipping by cart item quantity, frontend promotion boxes, and GitHub-based plugin updates.

## Features

- Quantity discount tiers shown as a frontend list box.
- Coupon/free-shipping offer list box with copy-code buttons.
- Better responsive UI for product, cart, and checkout pages.
- Admin settings under **WooCommerce → Buy More Save More**.
- Automatic best-tier discount application.
- Optional free-shipping rule by total cart quantity.
- GitHub updater using the latest GitHub release tag.

## Default offers

### Quantity discount list

- 2 items get 5% OFF on cart total
- 3 items get 7% OFF on cart total
- 4 items get 10% OFF on cart total
- 5 items get 15% OFF on cart total

### Coupon/free-shipping list

- `GET10` — Discount 10% for order of 2 items
- `FREESHIPPING3` — Free shipping for order of 3 items

## GitHub updates

Create a GitHub release with a tag higher than the installed version, for example `v1.0.1`. WordPress will check the repository release API and show an update in **Plugins** when a newer release exists.
